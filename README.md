# Stoneridge Digital — Website

A premium, light-editorial marketing-agency site (warm cream · forest green · copper). No build step, no framework — pure HTML/CSS/JS.

### Wow-moments / features
1. **Branded intro** — the ridge logo draws itself in on load, then reveals the site.
2. **Parallax mountain hero** — layered ridges drift with the mouse; the headline word rotates (local market → phone lines → calendar → revenue).
3. **Live Growth Dashboard** (`#growth`) — an animated "command center": KPIs count up & tick live, an ascending traffic chart, and a real-time activity feed (leads, rankings, reviews) that streams new events. Shows prospects what they get.
4. **Before / After drag slider** (`#difference`) — drag the handle to reveal the transformation.
5. **Self-drawing growth chart** — SVG line animates as you scroll into the results section.
6. **Auto-rotating testimonials** + **FAQ accordion**.
7. **Subtle contact** — the big form is gone; just an email line + the Book-a-Call section.

### Pages (23) + sitemap.xml + robots.txt
Bespoke: `index.html` (home), `seo-audit.html` (audit tool), `join.html` (careers/onboarding).
Generated by `build.cjs`:
- **Services:** `services.html` + `websites.html`, `seo.html`, `advertising.html`, `social-content.html`, `automation.html`
- **Company:** `about.html`, `work.html`, `industries.html` (Who We Serve), `process.html`, `faq.html`, `contact.html`, `book.html`
- **Insights:** `blog.html` + articles `insights-local-seo.html`, `insights-website-converts.html`, `insights-content-system.html`
- **Utility:** `privacy.html`, `terms.html`, `404.html` (all `noindex`)
- **SEO:** `sitemap.xml`, `robots.txt` (auto-generated; update `DOMAIN` in build.cjs)

> The legal pages are solid templates — have counsel review before launch. Point your host's 404 handler at `404.html`.

### Regenerating pages
The service + company pages come from one shared template so they stay consistent.
Edit `build.cjs` (content/nav/footer live there), then run:
```bash
node build.cjs        # regenerates the 12 template pages
```
`index.html`, `seo-audit.html`, and `join.html` are hand-built and NOT touched by the build — if you change the nav, update it there too.

### Motion
Site-wide: branded intro, parallax mountains (`[data-parallax]`), scroll-reveal with direction variants (`data-anim="left|right|zoom"`), animated Services mega-menu, button shimmer, floating logo marks, 3D-tilt cards, rotating hero word, page-entrance fade, active-nav highlight.

### Conversion & SEO layer (auto, site-wide)
Injected by `app.js` on every page — nothing to wire per page:
- **Sticky mobile call/book bar** + **header click-to-call** (edit the number in `SITE` at the top of the conversion block in `app.js`)
- **Skip-to-content link**, **keyboard-accessible dropdown**, **smart forms** (mobile keyboards + on-blur validation)

Baked into `build.cjs` `layout()` for all generated pages (and added by hand to `index.html`/`seo-audit.html`):
- **Canonical URL**, **OpenGraph + Twitter** tags, **JSON-LD schema** (Organization/LocalBusiness + WebSite; Service / FAQPage / Article per page type)
- **Analytics slot** — a commented GA4/Plausible block in `<head>`; paste your snippet to enable
- **Social image** — OG tags point to `assets/og-image.png`. Create it by opening **`og-card.html`** and screenshotting the 1200×630 card, then saving as `assets/og-image.png`.

> Set your real domain in `build.cjs` (`DOMAIN`) before launch — canonicals, OG URLs, sitemap, and schema all use it.

## 🔧 Three things to configure (5 minutes)

Everything runs today; these turn on live email + reliable audits. Search the files for `YOUR_` to find each spot.

### 1. Email — routes every lead to admin@stoneridgedigital.com
Uses **Web3Forms** (free, no backend, works on any static host).
1. Go to **https://web3forms.com** → enter **admin@stoneridgedigital.com** → get your Access Key.
2. Paste it in **three** places (replace `YOUR_WEB3FORMS_ACCESS_KEY`):
   - `index.html` → contact form hidden input
   - `seo-audit.html` → audit form hidden input
   - `assets/audit.js` → `CONFIG.WEB3FORMS_KEY`
3. To also email a copy **to the visitor**: in the Web3Forms dashboard turn on **Auto-Response** (the form already sends the visitor's address as reply-to).

All contact submissions, call requests, and audit results land in **admin@stoneridgedigital.com**.

### 2. SEO Audit — real Lighthouse scores
The audit calls **Google PageSpeed Insights**. It works without a key but shares a small anonymous quota (which can run out — you'll see a graceful fallback). Add a free key so it always works:
1. Get one at **https://developers.google.com/speed/docs/insights/v5/get-started**.
2. Paste it in `assets/audit.js` → `CONFIG.PSI_KEY`.

If a scan can't run, the tool still captures the lead and invites a manual audit — nothing breaks.

### 3. Book-a-Call — connect your calendar
The three call types (New Client Discovery / Current Client Check-in / Design-Strategy) fall back to the contact form until you add scheduler links. In `assets/app.js` → `CONFIG.booking`, paste your **Calendly / Cal.com / TidyCal** URLs:
```js
booking: {
  new:     "https://calendly.com/stoneridge/discovery",
  current: "https://calendly.com/stoneridge/client-checkin",
  design:  "https://calendly.com/stoneridge/design-strategy",
}
```
